# xiaoxu.me

Personal research website of Xiao Xu. Plain HTML/CSS, hosted on GitHub Pages.

- `index.html` — all page content
- `assets/styles.css` — design
- `assets/img/` — portrait and paper figures
- `papers/` — hosted PDFs
- `CNAME` — custom domain for GitHub Pages

To update: edit files, commit, and push to `main`. GitHub Pages republishes automatically within a minute or two.
